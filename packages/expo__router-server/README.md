# @expo-harmony/expo__router-server

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo__router-server)

本包为 HarmonyOS 上的 React Native 应用提供 Expo Router 配套支持，与官方同版本的 `@expo/router-server` 配套使用。

## 安装

```bash
npm install @expo-harmony/expo__router-server @expo/router-server
```
