# @expo-harmony/expo-keep-awake

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo-keep-awake)

为 HarmonyOS 上的 React Native 应用提供 Expo KeepAwake 的原生实现，用于在需要时保持设备屏幕常亮并恢复系统休眠行为，与官方同版本的 expo-keep-awake 配套使用。
