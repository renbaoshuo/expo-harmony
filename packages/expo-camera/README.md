# @expo-harmony/expo-camera

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo-camera)

为 HarmonyOS 上的 React Native 应用提供 Expo Camera 的原生实现，支持运行时相机和麦克风权限、前后摄切换、相机预览、拍照、录像、缩放、闪光灯、手电筒、对焦，以及预览的暂停和恢复，与官方同版本的 `expo-camera` 配套使用。

## 安装与使用

同时安装官方 JavaScript 包和本包提供的 HarmonyOS 原生实现：

```sh
yarn add expo-camera @expo-harmony/expo-camera
```
