# @expo-harmony/expo-network

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo-network)

为 HarmonyOS 上的 React Native 应用提供 Expo Network 的原生实现，与官方同版本的 `expo-network` 配套使用。支持读取当前网络类型、连接和互联网可达状态、默认网络接口的 IPv4 地址、飞行模式状态，以及订阅网络状态变化。

该原生库会声明 `ohos.permission.GET_NETWORK_INFO` 权限。JavaScript API、类型和 React Hook 由官方 `expo-network` 包提供。
