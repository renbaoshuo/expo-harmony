# @expo-harmony/expo__json-file

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo__json-file)

为 HarmonyOS 项目使用的 Expo 配置工具提供 JSON 文件读写能力，并与 `@expo/json-file` 配套使用。

## 安装

本包适配 Expo SDK 57。

```bash
npm install @expo-harmony/expo__json-file @expo/json-file@11.0.1
```
