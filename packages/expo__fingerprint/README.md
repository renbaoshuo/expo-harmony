# @expo-harmony/expo__fingerprint

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo__fingerprint) | [Expo Fingerprint 官方文档](https://docs.expo.dev/versions/v57.0.0/sdk/fingerprint/)

为 HarmonyOS 上的 Expo 项目提供项目指纹工具，与官方同版本的 `@expo/fingerprint` 配套使用。

## 安装

本包适配 Expo SDK 57。

```bash
npm install @expo-harmony/expo__fingerprint @expo/fingerprint@0.20.14
```
