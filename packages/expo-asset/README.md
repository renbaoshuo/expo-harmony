# @expo-harmony/expo-asset

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo-asset)

为 HarmonyOS 上的 React Native 应用提供 Expo Asset 的原生实现，支持缓存和加载 HTTP(S) 远程资源、`asset://` / `rawfile://` 应用内打包资源以及本地文件，与官方同版本的 `expo-asset` 配套使用。
