# @expo-harmony/expo-processing

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo-processing)

为 HarmonyOS 上的 React Native 应用提供 Expo Processing 支持，与 `expo-processing` 配套使用。

## 安装

本包适配 Expo SDK 57。

```bash
npm install @expo-harmony/expo-processing expo-processing@~57.0.20 expo-gl@~57.0.2 processing-js
```
