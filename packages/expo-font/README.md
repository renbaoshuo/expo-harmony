# @expo-harmony/expo-font

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo-font)

为 HarmonyOS 上的 React Native 应用提供 Expo Font 的原生实现，支持在运行时加载和注册自定义字体、将文字渲染为图片，并通过配置插件打包字体资源，与官方同版本的 expo-font 配套使用。
