# @expo-harmony/expo__env

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo__env)

为 HarmonyOS 上的 Expo 项目提供 `.env` 环境变量加载工具，与官方 `@expo/env` 配套使用。

## 安装

本包适配 Expo SDK 57。

```bash
npm install @expo-harmony/expo__env @expo/env@~2.4.3
```
