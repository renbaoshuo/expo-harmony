# @expo-harmony/expo-fetch

[**GitHub 仓库**](https://github.com/renbaoshuo/expo-harmony/tree/master/packages/expo-fetch)

为 HarmonyOS 上的 React Native 应用提供 Expo Fetch 的原生实现，支持 HTTP(S) 和本地文件请求、流式响应、重定向及 Cookie 处理，与官方同版本的 expo 配套使用。
